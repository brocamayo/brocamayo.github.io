# Card visuals

The live site uses the designed SVG mocks in `index.html`. There are no screenshot files in this folder, and the public page does not request any.

If you later want a real screenshot on a card, add the PNG here and an `<img>` tag in that card’s `.shot` block (above the SVG). Expected names:

- spend-dashboard.png   — Power BI Department Spend dashboard
- jira-dashboard.png    — MEME Fab / PCM Jira dashboard
- roi-pedestrian.png    — Pedestrian Detection ROI calculator
- python-scraper.png    — PDF quote scraper code
- power-automate.png    — Power Automate flow
- lithium-case.png      — Lithium battery business case
